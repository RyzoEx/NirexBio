# 🌟 Guns.lol Clone / Bio Link Profile Page

Современная кастомная страница профиля (био-ссылка) с эффектом матового стекла (**Glassmorphism**), **3D Parallax Tilt** анимацией, интерактивным **SVG-медиаплеером**, двойным плавным курсором и системой приоритета аудио и фонов согласно техническому заданию.

---

## 🚀 Быстрый запуск

Страница построена на чистом, оптимизированном стеке **HTML5 + Vanilla CSS + Vanilla JS** (без тяжелых библиотек и без необходимости сборки).

### Вариант 1. Через Python
```bash
python -m http.server 3000
```
Затем откройте в браузере: `http://localhost:3000`

### Вариант 2. Через Node.js / npx
```bash
npx serve .
```

### Вариант 3. Напрямую
Просто дважды кликните по файлу `index.html` в проводнике Windows.

## 💎 Реализация требований Технического Задания

### 1. Архитектура и Структура (Размеры и Сетка)
* **Контейнер карточки:**
  * Фиксированная ширина `520px` с адаптивностью `max-width: 90%` на смартфонах.
  * Форма и стиль: `border-radius: 22px`, фон `rgba(15, 15, 15, 0.45)`, `backdrop-filter: blur(16px)`, граница `1px solid rgba(255, 255, 255, 0.1)`.
  * Внутренние отступы `24px`, идеальное центрирование по центру экрана (`min-height: 100vh`).
* **Шапка профиля:**
  * Аватар: `80x80px`, круглый (`border-radius: 50%`), неоновая окантовка и пульсирующий индикатор онлайн-статуса. Поддерживает JPG, PNG, WebP и анимированные GIF.
  * Никнейм: `24px`, жирный (`font-weight: 700`) шрифт **Syne** / **Outfit**.
  * Интерактивные SVG-бейджи: Verified, Server Booster, VIP Diamond с анимацией при наведении.
  * Био / Статус: `14px`, контрастность `opacity: 0.85`.
  * Мета-информация: `12px` («Member since Mar 2023 • UID: #1337»).
* **Интерактивный плеер:**
  * Внутренний стеклянный блок: `border-radius: 12px`, фон `rgba(0, 0, 0, 0.32)`, `padding: 12px`.
  * Обложка: `48x48px` с закруглением `8px` и световой пульсацией при воспроизведении.
  * Инфо о треке: Название трека (`14px`, bold), кликабельные исполнители (`12px`).
  * Интерактивный таймлайн: перетаскиваемый ползунок прогресса с индикацией текущего времени (`01:49 / 03:24`).
  * Все элементы управления строго в векторном формате **SVG**: Play / Pause, сердечко избранного (Like с анимацией), Loop (повтор).
* **Социальные сети и футер:**
  * Сетка из 6 векторных SVG-иконок (Discord, Telegram, GitHub, Spotify, Steam, Twitter/X) с плавным увеличением `scale(1.1)`, неоновым свечением, тултипами и кликом для копирования тега.
  * Футер с векторным глазом (счетчик просмотров `28,490`) и маркером локации (`Neo-Tokyo, JP`).

### 2. Динамика и Интерактивность

1. **3D Parallax Tilt Effect (`js/tilt.js`):**
   * Расчет наклона по осям X и Y за курсором мыши (угол наклона до `12°`).
   * Реалистичный стеклянный блик (`glare: true`, `radial-gradient`), следующий за углом падения света.
   * Плавный сброс в нейтральное положение при уходе мыши.
   * Эффект 3D-глубины (`translateZ`) для внутренних слоев карточки (аватар, плеер, соцсети).
2. **Кастомный GIF / PNG-курсор (`js/cursor.js`):**
   * Поддерживает любые форматы: **`.gif` (включая анимированные GIF)**, **`.png`**, **`.webp`**, **`.svg`**.
   * По умолчанию подключен анимированный кибер-курсор [assets/cursor.gif](file:///d:/BioProfile/assets/cursor.gif).
   * **Авто-масштабирование до фиксированного размера:** независимо от разрешения исходного файла (хоть `1080x1080` px или больше), браузер жестко форматирует его до фиксированного размера (по умолчанию `28x28` px).
   * Мгновенный отклик, масштабирование и неоновое свечение при наведении на интерактивные кнопки, ссылки и плеер.
   * Автоматически отключается на смартфонах с сенсорным экраном (`@media (pointer: coarse)`).
3. **Плавающий Mute Toggle:**
   * В левом верхнем углу экрана расположена стеклянная плашка с SVG-иконкой звука и анимированным 3-полосным эквалайзером.
4. **Фирменный guns.lol экран входа:**
   * При первом открытии экран затемнен с размытием и мигающей надписью `[ click anywhere to enter ]`.
   * По клику оверлей плавно растворяется, запуская звук в полном соответствии с правилами современных браузеров (User Gesture Autoplay Policy).

### 3. Логика Приоритета Звука (Audio Priority)

В проекте реализована строгая логика приоритетов согласно ТЗ:

* **Сценарий А (Загружен отдельный аудиофайл):**
  * В категории «Звук» подключен `assets/audio.mp3`.
  * Фоновое видео автоматически глушится (`muted = true`).
  * Интерактивный плеер управляет треком `audio.mp3` (воспроизведение, пауза, таймлайн).
* **Сценарий Б (Отдельный звук отсутствует):**
  * Отдельный звук отключен.
  * Плеер подключается к звуковой дорожке **видео-фона** (`muted = false`) и синхронно управляет им.
* **Сценарий В (Фон — статичное фото/GIF):**
  * На фоне статичное изображение/GIF и звук не загружен.
  * Плеер переходит в режим ожидания (неактивен, шкала прогресса скрыта или выключена).
